## Savings Calculator
This repository now includes a simple command-line tool `savings_calculator.py`.

Run it with Python 3 to calculate how much you need to save each day, week, and month to reach a savings goal.

```
python3 savings_calculator.py
```

The app will prompt for your monthly income, target amount, the item you want to buy, and when you plan to buy it (YYYY-MM-DD).
